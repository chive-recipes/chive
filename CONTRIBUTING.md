# Contributing

Issues and pull requests are welcome for the public Chive web application.

Before opening a pull request, run:

```sh
npm ci
npm run build
npm run typecheck:worker
npm run test
```

Keep changes to `public/index.json` separate from application changes. That file
is generated by Chive's private polling service and should not be edited by
hand.

License.
